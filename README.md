## 🌌 Ecossistema NEXUS & Projetos em Destaque

### 1. Ecossistema NEXUS ([`PaulNasc/nexus`](https://github.com/PaulNasc/nexus))

O **NEXUS** é o meu principal ecossistema pessoal de software: um espaço de trabalho desktop minimalista projetado para unir organização de tarefas, escrita técnica, foco e colaboração sem ruído visual.

<p>
  <a href="https://github.com/PaulNasc/nexus/releases/latest">
    <img src="https://img.shields.io/github/v/release/PaulNasc/nexus?style=flat-square&label=Release%20Atual&color=00C29D" alt="Release atual do Nexus" />
  </a>
  <a href="https://github.com/PaulNasc/nexus/commits">
    <img src="https://img.shields.io/github/last-commit/PaulNasc/nexus?style=flat-square&label=%C3%9Altimo%20Commit&color=008E9B" alt="Último commit no Nexus" />
  </a>
  <a href="https://github.com/PaulNasc/nexus">
    <img src="https://img.shields.io/github/stars/PaulNasc/nexus?style=flat-square&label=Stars&color=0F172A" alt="Stars no Nexus" />
  </a>
</p>

- **Fluxo de Produtividade Integrado:** Quadro Kanban (`Backlog` → `Esta Semana` → `Hoje` → `Concluído`), editor de notas em **Markdown** com vinculação bidirecional às tarefas, timer **Pomodoro** com métricas e *streaks* de foco, além de insights semanais de desempenho.
- **Colaboração & Mídia:** Suporte a organizações, sistema de **Ping** direcionado com notificações nativas no Windows e anexos de imagens, PDFs e vídeos.
- **Arquitetura Desktop Adaptativa:** Evoluído de **Electron** para **Tauri v2** (**Rust** + WebView2) com camada de abstração (`desktopAdapter.ts`) compatível com Tauri, Electron e Web, mantendo interface em **React + TypeScript + CSS**.
- **Persistência Híbrida & Privacidade:** Modos **Local**, **Nuvem** e **Híbrido** com **Supabase** (OAuth Google/Discord, PostgreSQL com RLS e Realtime WebSockets) e **Cloudflare R2** via URLs assinadas, além de distribuição nativa via instalador Windows e versão portátil.

### 2. goState ([`PaulNasc/gostate`](https://github.com/PaulNasc/gostate))

Plataforma corporativa voltada à orquestração e execução visual de testes automatizados E2E com **Playwright**, conectando diretamente minha vivência em QA com engenharia de ferramentas internas.

- **Construtor Visual & Execução Distribuída:** Editor visual de fluxos em Canvas (**React Flow**), gerenciamento centralizado de casos e suítes de teste e editor integrado de scripts Playwright.
- **Tempo Real & Observabilidade:** Agentes remotos conectados via WebSockets (**Socket.IO**), streaming de logs, histórico com vídeos e capturas de tela de falhas, backend em **Express + SQLite**, frontend em **React + Vite + Tailwind CSS** e empacotamento com **Docker Compose**.
